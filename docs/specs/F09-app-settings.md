# F09 应用设置

- 状态：已实现
- 关联：[ADR 0036](../adr/0036-authoritative-durable-app-settings.md)

## 概述

应用设置是设备本地、全局且跨重启保存的偏好。首页、设置页与新草稿使用同一组设置；新选择保存成功后才会生效。

## 范围

- 新草稿的照片信息策略默认值。
- 草稿 Grid 的缩略图显示方式。

## 非目标

- 改写草稿已经明确保存的导出照片信息策略。

## 需求与场景

### 需求 1：设备本地全局偏好

#### Scenario: 首次使用采用 privacy-first 默认值

- GIVEN 设备本地尚无设置记录
- WHEN 应用完成设置初始化
- THEN 新草稿的照片信息策略默认为“移除全部照片信息”
- AND 草稿 Grid 的缩略图显示方式默认为“正方形”

#### Scenario: 两个入口观察同一设置事实

- GIVEN 应用已经完成设置初始化
- WHEN 用户在设置页改变新草稿的照片信息策略默认值
- AND 返回仍挂载的首页改变草稿缩略图显示方式
- THEN 再次打开设置页时照片信息策略保持用户选择
- AND 首页显示方式保持用户选择
- AND 两个设置跨应用重启后仍然保留

### 需求 2：设置字段独立更新

#### Scenario: 不同字段的交错更新互不覆盖

- GIVEN 照片信息策略与缩略图显示方式均已有已保存值
- WHEN 两个入口先后或并发提交不同字段的变更
- THEN 最终设置同时保留两个字段最后保存成功的选择

### 需求 3：保存成功后才发布新值

#### Scenario: 保存期间继续展示旧值

- GIVEN 用户提交一项设置变更
- WHEN 设备存储尚未确认保存成功
- THEN 对应交互保持禁用
- AND 首页与设置页继续展示原有已保存值
- WHEN 保存成功
- THEN 两个入口同时观察到新值

#### Scenario: 保存失败保留旧值并允许重试

- GIVEN 用户提交一项设置变更
- WHEN 设备存储写入失败
- THEN 应用显示本地化错误
- AND 首页与设置页继续展示原有已保存值
- AND 用户可以再次提交该变更
- AND 本次失败不阻止后续其他设置变更成功

#### Scenario: 保存中断后不出现混合设置

- GIVEN 应用已经保存一组设置
- WHEN 应用在保存下一组设置的过程中终止
- THEN 重新启动后显示完整的旧设置或完整的新设置
- AND 不显示两次保存结果混合而成的设置

### 需求 4：读取失败与损坏降级

#### Scenario: 瞬时读取失败不覆盖已有设置

- GIVEN 设备本地存在一份有效设置记录
- WHEN 初始化因临时存储故障无法读取
- THEN 新草稿安全降级为移除全部照片信息，首页安全降级为正方形显示
- AND 设置控件不可提交并提供重试
- WHEN 存储恢复且用户重试初始化
- THEN 应用读取并展示原有设置

#### Scenario: 损坏记录回退安全默认值

- GIVEN 已保存的设置内容损坏
- WHEN 应用完成设置初始化
- THEN 应用采用 privacy-first 默认值作为当前设置
- WHEN 用户之后明确改变设置
- THEN 新的有效设置可以正常保存
