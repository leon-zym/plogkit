# F02 背景

- 状态：已实现

## 概述

为照片设置背景色与输出比例。这是一个快速任务流，不是图层编辑器。

## 非目标

- 边距/内边距、边框、圆角。
- 渐变/图片背景、阴影。

## 需求与场景

### 需求 1：背景色

#### Scenario: 设置背景色

- GIVEN 一个含单张图片的编辑会话
- WHEN 用户选择白色背景
- THEN 预览显示图片周围由白色背景填充（按当前输出比例）
- AND 点击一次撤销后恢复原背景色

### 需求 2：输出比例

#### Scenario: 切换输出比例

- GIVEN 一张 4:3 的横图
- WHEN 用户选择 3:4 输出比例
- THEN 画布变为 3:4，图片完整保留并居中显示，多余区域由背景色填充

#### Scenario: 恢复原始比例

- GIVEN 画布处于 3:4 比例
- WHEN 用户选择「原始比例」
- THEN 画布恢复为图片原始宽高比
